✅ Automatic on every device

This site saves to your Google Drive save spot. Just open the site on any device and your records are there. No sign-in or setup per device.

File in your Google Drive: joseph-wharton-progress.json (plus one dated backup per day). Your Anthropic API key is never saved there; add it in each device's Settings.

Turn on the Google save spot (one time, about 3 minutes)

  1. Go to script.google.com → New project (signed in to the Google account you want to use). Name it Joseph Wharton save spot.
  2. Delete what's in Code.gs and paste in the code from google-apps-script/Code.gs. Click 💾 Save.
  3. Choose the function setup in the toolbar and click ▶ Run, then allow access (Advanced → Go to project → Allow). This creates the file in your Drive.
  4. Deploy → New deployment → ⚙ type Web app → Execute as: Me · Who has access: Anyone → Deploy, then copy the Web app URL (ends in /exec).
  5. Send that URL to Claude and it gets built into the site. After that, every device syncs automatically.
Advanced: use a private GitHub repo + token instead

Connect this device

Already set up on another device? Open the “setup link” from that device here, or paste the same token below.

First time? One-time setup (about 3 minutes)
  1. Create the private data repo. Go to github.com/new. Name it joseph-wharton-data, choose Private, tick Add a README file, then click Create repository.
  2. Create an access token for it. Go to github.com/settings/personal-access-tokens/new (Fine-grained token):
    • Token name: Joseph Wharton sync. Expiration: as long as you like (e.g., 1 year).
    • Repository access: Only select repositories → joseph-wharton-data.
    • Permissions → Repository permissions → Contents: Read and write. (Metadata: Read-only is added automatically.)
    • Click Generate token and copy it (starts with github_pat_).
  3. Paste it above and click Connect. Your existing progress on this device is uploaded right away.
  4. Other devices: click “Copy setup link…” and open that link once on your phone or other computer. Done: they're all synced.

The token can only touch joseph-wharton-data, nothing else in your account. It's stored on each device you connect. To revoke it anytime, delete it at github.com/settings/personal-access-tokens.
